2. Modes of the Agentic modes - Ask, Edit and Agent mode
		- Ask - least consumption - where I have a question or prompt to ask
		- Edit -High consumption (but less compared to Agentic) Where you are trying to add to the existing code such as adding a method to the existing class, refactoring the code 
		- Agentic - Higher consumption - Address the complex issues, it might lead to multiple edits across the files of your application
		- This consumption is also known as "Token burnout"

What is propel-IQ

		- It is a framework
		- It has a list of precompiled prompts
		- Each prompt is meant for specific role and specific phase of the SDLC
		- Modular prompts - Execute them and have a human-in-the-loop
		- It uses the approach called "Multi-agent responsibility", e.g. it uses discovery agent, a design agent, an architect agent etc.,
